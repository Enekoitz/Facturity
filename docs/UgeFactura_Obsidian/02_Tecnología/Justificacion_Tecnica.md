La aplicación se desarrollará sobre ASP.NET 8 con una arquitectura limpia para garantizar independencia y desacoplamiento entre capas. Proporcionando mantenibilidad, testabilidad y escalabilidad.

Se utilizará Angular para el frontend por su modularidad, robustez y estructura. También se integra con gran afinidad con el entorno y tecnologías .NET.

La persistencia de datos se fundamente en PostgreSQL. Potente y sin costes de licencia. Alta integridad con .NET.

Uso de Entity Framework Core para el acceso a datos (ORM), Serilog para la gestión de logs (logging) y xUnit para las pruebas unitarias.

Obtenemos reconocimiento y extracción de textos mediante OCR (ROC en español "Reconocimiento Óptico de Caracteres"), lo que permite digitalizar facturas manuscritas, automatizando y reduciendo errores.
