Aplicación web monolítica y modular.

Haciendo uso de arquitectura limpia y un enfoque DDD, poniendo el dominio como centro desacoplado de la aplicación.

Gran énfasis en el uso sistemático de principios SOLID.

Implementamos pruebas unitarias para todo, intentando cubrir el máximo de escenarios posibles.

Damos importancia a sistemas seguros. La aplicación debe de tener implementados mecanismos de seguridad tanto a nivel de código y aplicación como a nivel de entorno (servidor, nube...)
