Es obligatoria la facturación digital mediante Ticketbai en el territorio de Bizkaia.
La aplicación web pública proporcionada por la Diputación Foral de Bizkaia, "Haz tu factura", permite introducir, generar y enviar a hacienda las facturas de las operaciones realizadas.
- Perdida de tiempo: introducción manual de datos (productos, importe, descripción, fecha de operación, etc.)
- Sin posibilidad de utilizar datos de las facturas generadas para obtener información valiosa.
- Proclive a introducción errónea de datos o valores, proclive a errores por falta de automatización.
