## Documentación

Toda la documentación vive en [`/docs`](docs/index.md) (docs-as-code).

Para verla como sitio web en local:

```bash
pip install mkdocs-material
mkdocs serve
```

## Cómo empezar un proyecto nuevo con esta plantilla

1. Crea el repo desde esta plantilla (o copia la carpeta).
2. Sigue el orden de [`PROCESO.md`](PROCESO.md): visión → alcance → stakeholders → glosario → requisitos → dominio → arquitectura.
3. Haz primero una **versión mala** de cada documento. Pulir viene después.
4. Borra lo que no uses (runbooks, research...) si el proyecto es pequeño.
